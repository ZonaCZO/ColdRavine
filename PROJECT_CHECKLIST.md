## Правила разработки

Сохранять простую архитектуру: состояние страницы и компоненты с props. Типы брать из src/types. Не добавлять несовместимые поля. Новые темы разбирать с пользователем; знакомый повторяющийся frontend можно готовить целиком по его просьбе.

Сейчас Soldier.unit — название подразделения; Unit.commander — ID солдата или null. Состав фильтруется по названию, командир показывается отдельно. Переход к unitId потребует обновить все потребители.

Сервер пока на JavaScript. Данные и сессии в памяти исчезают после перезапуска; TypeScript backend и постоянное хранилище не завершены.
