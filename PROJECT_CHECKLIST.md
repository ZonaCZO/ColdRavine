Репозиторий: https://github.com/ZonaCZO/ColdRavine

Полная структура: APPLICATION_PLAN.md.

## Основа

React + TypeScript. Сохранять простую структуру: страница управляет состоянием, компоненты карточек и фильтров получают данные через props. Использовать существующие типы из src/types. Не добавлять поля к сущностям без согласованного изменения типа и данных.

Оформление: тёмный фон, бирюзовые акценты, компактные панели поиска и фильтров. Personnel и Units — адаптивная сетка карточек, изображение или эмблема сверху, текст снизу.

План — ориентир для следующих задач, а не требование немедленно реализовать весь проект. Это ручной чек-лист, не автоматический тест.

## Связи данных

Operation → назначенные Units → Soldiers.
Intelligence Report → связанная Operation → отображение на карте.
Dashboard → сводка по общим данным.

Пока Soldier.unit — строка. Не менять её на unitId без обновления всех потребителей. Не вводить фиктивные связи и выдуманную численность в карточках. Когда потребуются общие данные, вынести их из страниц в единый источник; hooks/ и api/ добавлять по необходимости.
